What it does

Ten sections on the original page, rebuilt here as the six that carry the architecture.

01

Instant codebase understanding

Maps large repositories in seconds through the TokenFold retrieval layer: architecture, dependencies, execution flow, without attaching files by hand.

02

Issue to shipped PR

Reads the ticket, writes the code, runs the tests, fixes what fails, opens the pull request in one continuous run.

03

Multi-file execution

Refactors across hundreds of files with dependency-aware edits that stay structurally consistent.

04

TokenFold architecture

Indexes the repository once, keeps the index current, and gives the model only the code that matters per request. Fewer tokens, whole repo in reach.

05

Flux router

A classified router model picks the right model per request and bills one flat rate whichever model answers.

06

Safe execution layer

Every edit and command is shown before it runs. Nothing lands without approval.

Questions

What is Superbrain?

An AI coding agent for teams in large codebases: describe the change, it reads, plans, edits across files, runs the tests and prepares the PR. Built on the TokenFold retrieval architecture.

How is it different from Claude Code, Cursor or Copilot?

The original's answer is measured efficiency on a ten-bug django slice of SWE-bench Lite, self-graded, with the runs they lost published alongside.

How does it handle monorepos?

TokenFold indexes the repo once and keeps the index current, so a change in a million-line repository costs about the same as one in a small project.

Does it change code without asking?

No. Every edit, command and refactor is shown before it runs.
